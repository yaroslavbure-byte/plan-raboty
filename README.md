# План работы — инструкция

## 1. Быстрый старт (без сервера)
Установите `Plan-Raboty-Setup-1.0.0.exe`. Установщик не подписан, поэтому Windows может показать окно
«Windows защитила ваш компьютер». Нажмите **Подробнее → Выполнить в любом случае**.

При первом запуске выберите **«Попробовать без сервера»**. Все функции для одного человека работают сразу:
задачи, календарь, «Позже», цели, идеи, повторы, история, перетаскивание. Данные хранятся только на этом компьютере.

## 2. Сервер для двоих (Supabase, бесплатно)
1. Зарегистрируйтесь на https://supabase.com и нажмите **New project** (тариф Free).
2. Откройте **SQL Editor → New query**, вставьте весь файл `supabase/schema.sql` и нажмите **Run**.
3. Откройте **Authentication → Sign In / Providers → Email** и выключите **Confirm email**
   (иначе после регистрации придётся подтверждать почту по письму — это тоже работает, просто дольше).
4. В **Project Settings → API** скопируйте **Project URL** и ключ **anon public**.
   Это публичный ключ: его можно хранить в приложении, данные защищает Row Level Security.
   Ключ `service_role` никуда не вставляйте.
5. В приложении на Windows: **⋯ → Аккаунт и пара → Подключить сервер** (или экран первого запуска).
   Вставьте URL и ключ, затем зарегистрируйтесь.

Тариф Free: если проект 7 дней никто не открывает, Supabase ставит его на паузу.
Снять паузу можно бесплатно одной кнопкой в панели Supabase.

## 3. Версия для iPhone и Android (PWA)
1. Распакуйте `Plan-Raboty-web.zip`.
2. Впишите свой URL и anon key в файл `config.json`. Тогда на телефоне не придётся ничего вводить.
3. Откройте https://app.netlify.com/drop и перетащите туда папку целиком. Это бесплатно, и вы сразу
   получите HTTPS-адрес вида `xxx.netlify.app` (в настройках сайта его можно переименовать).
4. **iPhone:** откройте адрес в Safari → **Поделиться → На экран «Домой»**. Запускайте приложение с иконки.
   **Android:** откройте адрес в Chrome → меню → **Установить приложение**.

## 4. Как связать два аккаунта
Каждый регистрируется со своего устройства. Дальше у одного из вас: **⋯ → Аккаунт и пара** — там лежит код
из 6 символов. Второй вводит этот код у себя в том же окне и нажимает **«Связать»**.
После этого появится переключатель **Я | ♥ Общие | Партнёр**.

## 5. Уведомления
- **Внутренний центр уведомлений** (колокольчик) работает всегда.
- **Windows:** пока приложение запущено (в том числе свёрнуто в трей), приходят системные уведомления.
- **Web Push (iPhone с iOS 16.4+ с домашнего экрана, Android):** нужна дополнительная настройка.
  1. Сгенерируйте ключи командой `npx web-push generate-vapid-keys`.
  2. Установите Supabase CLI и выполните `supabase functions deploy push --no-verify-jwt`.
     Затем задайте секреты: `supabase secrets set VAPID_PUBLIC_KEY=... VAPID_PRIVATE_KEY=... VAPID_SUBJECT=mailto:you@mail.com`.
  3. В Supabase откройте **Database → Webhooks → Create**. Таблица `notifications`, событие **Insert**,
     тип **Supabase Edge Function** → `push`.
  4. Впишите публичный VAPID-ключ в `config.json` (поле `vapid`) и заново загрузите сайт на Netlify.
  5. На телефоне: **⋯ → Аккаунт и пара → Включить push-уведомления**.

## 6. Темы
В шапке есть шестерёнка → **Настройки → Тема**. Можно выбрать «Тёплая», «Ночная» или «Как в системе».
Тема запоминается на каждом устройстве отдельно.

## 7. Обновление приложения
**Windows.** Откройте **Настройки → Проверить обновления** → **Скачать** → **Перезапустить и установить**.
Задачи, вход и настройки сохраняются.
Приложению нужно знать, откуда брать обновления. Проще всего бесплатно хранить их в релизах GitHub.
У бесплатного Supabase ограничение 50 МБ на файл, а установщик весит около 83 МБ, поэтому Supabase не подходит.
1. Создайте публичный репозиторий, например `plan-raboty-releases`.
2. Нажмите **Releases → Draft a new release**, тег `v1.2.0`. Прикрепите `latest.yml`,
   `Plan-Raboty-Setup-1.2.0.exe` и `.blockmap`, затем нажмите **Publish**.
3. В приложении один раз впишите адрес обновлений:
   `https://github.com/ИМЯ/plan-raboty-releases/releases/latest/download`.

Кнопка обновления появилась в версии 1.1.0. Её нужно один раз установить вручную поверх 1.0.0, дальше обновления пойдут кнопкой.

**Телефон (PWA).** Откройте **Настройки → Обновить приложение**. Подтянется последняя версия, загруженная на сайт.

## 8. Подпункты, ссылки, видео (v1.2)
В окне задачи появились разделы **Подпункты**, **Ссылки** и **Видео и фото**.
- Подпункты видны прямо в списке под задачей, отмечать их можно там же.
- Видео смотрится сразу потоком, без скачивания. Кнопка **«⤓ скачать»** сохраняет копию на устройство,
  тогда видео играет без интернета.
- Лимит бесплатного Supabase: **50 МБ на файл** и **1 ГБ** на всё хранилище.
  На тарифе Pro ($25/мес) лимиты намного больше.
- Перед первым использованием нужен один SQL-запуск. Приложение само покажет жёлтую плашку
  с кнопками «Скопировать код» → «Открыть Supabase».

## 9. Обновления в одну кнопку (настраивается один раз)
Всё уже подготовлено в `.github/workflows/release.yml`. После настройки выпуск версии делается
одной командой, и всё происходит само:
- база данных обновляется сама;
- Windows-приложение само скачивает обновление и показывает кнопку «Перезапустить и обновить»;
- телефон получает новую версию при следующем открытии приложения, переустанавливать ничего не нужно.

Что нужно один раз:
1. Подключить GitHub в claude.ai: **Настройки → Connectors → GitHub**.
2. Создать публичный репозиторий `plan-raboty` и загрузить туда эти исходники.
3. В репозитории открыть **Settings → Secrets and variables → Actions** и добавить:
   - `SUPABASE_DB_URL` — Supabase → **Connect** → **Connection string (URI)** с паролем базы;
   - `SUPABASE_URL` и `SUPABASE_ANON_KEY` — те же значения, что в приложении;
   - `NETLIFY_AUTH_TOKEN` — Netlify → **User settings → Applications → Personal access tokens**;
   - `NETLIFY_SITE_ID` — Netlify → проект → **Project configuration → Project ID**.

## 10. Что проверено, а что нет
Проверено:
- Сборка и запуск интерфейса (десктоп, мобильная вёрстка, Electron).
- Добавление и отметка задач, разбор времени из текста («… 14:00»).
- SQL-схема на PostgreSQL: Row Level Security, связь по коду, запрет доступа посторонним,
  автор изменения и уведомление «Тебе добавили задачу».

**Не проверено вживую:**
- Загрузка видео в настоящий Supabase (в локальном режиме загрузка и просмотр проверены). Правила доступа к хранилищу проверены на PostgreSQL.
- Скачивание и установка обновления по кнопке. Проверю, когда выйдет следующая версия.
- Синхронизация клиента с настоящим проектом Supabase.
- Web Push.
- Установщик на настоящей Windows (собран под Linux).
- Реальные iPhone и Android.
